FAQ

Common questions

How does πX understand my data without configuration?
The Universal Data Intelligence Engine profiles every column using a 6-layer semantic mapping system. It detects entities, KPIs, relationships, and industry patterns automatically — then generates an Intelligence Profile unique to your organization.
What data sources does πX support?
Excel, CSV, PostgreSQL, MySQL, MongoDB, SAP, Salesforce, HubSpot, REST APIs, GraphQL, Kafka streams, and webhooks. The semantic mapping engine handles any schema.
How are AI agents created?
Agents are generated from your Intelligence Profile — each gets a role, tools, KPIs to monitor, and company-specific context. 10 agent types are available (Sales, Inventory, Customer, Production, Quality, Maintenance, Finance, Marketing, HR, Strategy).
Is my data secure?
Yes. Row-level security provides tenant isolation, PII detection masks sensitive fields before AI processing, and every AI action is logged in an immutable audit trail with chain integrity verification.
What AI providers are supported?
OpenAI, Anthropic (Claude), Google Gemini, DeepSeek, Ollama (local), and OpenRouter. The AI Gateway routes requests based on task complexity, cost, and latency — with automatic fallback chains.
Can I use Google OAuth to sign in?
Yes. πX supports Google OAuth via Supabase Auth, plus email/password authentication with JWT tokens. Both flows create your organization workspace automatically on first login.
